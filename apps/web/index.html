Questions Fréquentes

Tout ce que vous devez savoir pour démarrer sereinement.

Comment le système empêche-t-il la triche par faux GPS (Mock Location) ?

Winner Pointage utilise un algorithme de vérification multi-couches qui analyse les données brutes des capteurs matériels du téléphone. Si une application de simulation de position est détectée, le pointage est instantanément bloqué et une alerte est envoyée au manager.

Que se passe-t-il si la connexion internet est coupée sur le site ?

L'application enregistre les pointages en local de manière chiffrée avec horodatage sécurisé. Dès que le réseau est rétabli, les données se synchronisent automatiquement sans aucune perte.

Quel est le délai de déploiement dans notre entreprise ?

Moins de 24 heures ! Il vous suffit d'importer la liste de vos employés via un fichier Excel ou CSV, de configurer les coordonnées GPS de vos sites, et vos équipes peuvent commencer à pointer immédiatement.
